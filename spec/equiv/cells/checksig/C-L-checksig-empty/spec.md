# checksig/C-L-checksig-empty

SCR-109: `OP_CHECKSIG` on an empty signature pushes `vchFalse`, and
`OP_CHECKSIGVERIFY` raises ordinal 14.  The cell also exercises the
`CheckSignatureEncoding` empty-signature bypass (SCR-108's rule inside the
CHECKSIG path), the two pubkey policy gates that can abort first, the
concrete `CheckECDSASignature` empty-signature short-circuit, and the
continuation through `OP_NOT`.  Alive2 proves C ≡ L bidirectionally over
symbolic policy/encoding inputs; SAW proves each leg against an independent
Cryptol restatement.  The verdict is independent of pubkey validity, so no
ECDSA same-crypto premise is used.
