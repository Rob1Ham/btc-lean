# checksig/C-L-checksig-lows-numeric

The numeric half of `IsLowDERSignature`/`CPubKey::CheckLowS`, proved over the
**whole** 256-bit raw-S space rather than only the canonical `s < n` domain:

```
lowS off                                     -> 0
lowS on, s >= n                              -> 0   (parse_compact zeroes s)
lowS on, s <  n, s <= floor(n/2)             -> 0
lowS on, s <  n, s >  floor(n/2)             -> 27  SIG_HIGH_S
```

Alive2 compares the two leaves in both directions; SAW proves each leaf
against the independent Cryptol predicate `s % n <= floor(n/2)` (with
`red = if s >= n then s - n else s`).  The `s >= n` arm is the part the
existing `C-L-checksig-lows` cell excluded; this cell closes it for the
`Der.isLowDERSignature` model while R is canonical and no integer length
overflows.

**Still partial.**  The exact residual seam is filed in
`spec/equiv/findings/wave64/24-scr-104-low-s/SEAM.md`:

- Core's shared overflow flag also fires on R >= n, zeroing S; Der.lean
  ignores R, so a canonical-R premise is required.
- DER lengths > 32 after zero-stripping zero both integers in Core and in
  parseDerLax; that byte-level window is outside this numeric leaf.
- `Defs.checkLowS`, the Lean target cited by SCR-104, compares **raw** S to
  halfN, not S mod n.  It therefore disagrees with Core exactly on S >= n
  (and on the overflow windows above).  Closing SCR-104 requires changing
  the Lean seam, not another IR cell.
