# checksig/C-L-checksig-nullfail-hashtype

SCR-110: a failed check on a non-empty signature under NULLFAIL returns
ordinal 32, and that error outranks `OP_CHECKSIGVERIFY`'s ordinal 14.  The
guard's whole truth table (signature empty/non-empty, policy bit on/off,
checker verdict) is proved.  SCR-111: the trailing signature byte becomes
`nHashType`, its 0x80 bit is exactly ANYONECANPAY, and the low five bits
select the ALL/NONE/SINGLE class while bits 5..6 are ignored.  The checker
verdict is abstract, so SCR-110 carries the same-crypto premise; SCR-111's
decode is structural.
