# checksig/C-L-checksig-opcount

SCR-113: every opcode with wire byte greater than `OP_16` (0x60) in a base or
witness-v0 script adds exactly one to the 201-op budget, and the 202nd such
opcode fails with ordinal 7.  Eight symbolic opcodes are walked from a
symbolic start count; the execution flag provably does not affect the count.
No crypto premise.
