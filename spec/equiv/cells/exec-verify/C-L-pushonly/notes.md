# exec-verify/C-L-pushonly — notes

## Design

Three functions, all built on one bounded `IsPushOnly`:

- `cell_ispushonly(len, script)` — the predicate.  Script bytes are packed
  little-endian into a 64-bit word, `len` in 0..8; longer scripts are the
  declared out-of-model marker 3.
- `cell_pushonly_early(sigpushonly, len, script)` — interpreter.cpp:2022-2024.
  Core short-circuits on the flag, so with the flag off the predicate is not
  consulted; with it on, a non-push-only script yields `SIG_PUSHONLY` (26).
- `cell_pushonly_p2sh(p2sh, spk_p2sh, len, script)` — interpreter.cpp:2065-2066.
  The check is unconditional once the P2SH arm is entered.

The C leg is a line-cited excerpt of `IsPushOnly` + `GetScriptOp` with the
walk unrolled to eight steps.  The unrolling is not a weakening: for `len <=
8` every executed step consumes at least one byte, so eight steps always
reach the end; the step body is Core's loop body verbatim (direct push,
PUSHDATA1/2/4, truncation, the `opcode > OP_16` test).

The L leg is a reviewed transliteration of `parseWire` / `getOpAux` /
`isPushOnlyWire`.  It uses a shared `l_decode` helper that returns
`(next, nsize, ok)` and carries an explicit `(ok, push)` pair, so its IR shape
differs from the C early-return chain.

SAW verifies both legs against a third encoding: a Cryptol fold over an
8-element index sequence with a `(pc, ok, push)` state.  Byte `i` is
`(script >> (8*i)) & 0xff` via `reverse (split script)`.

## Disclosed deviation: one walk instead of two

Lean defines `parseWire` (first pass, all-or-nothing on truncated pushes)
followed by `isPushOnlyWire` (second pass, every wire byte <= 0x60).  The L
leg combines them into one walk.  The Boolean is unchanged: a truncation
sets `ok = 0`, an opcode > OP_16 clears `push`, and the result is
`ok && push` — both failure modes are false in either order.  Keeping the two
passes literally made both tools impractical on this machine (the doubled
ITE network blew past Alive2's query budget and SAW's abc proof exceeded
15 minutes per leg), so the cell combines them and says so here and in
`spec.md` under `trust_note`.  This is a shape deviation, not a predicate
weakening.

## Tool notes

- Alive2 needs a larger SMT budget than the default 10 s: `cell.conf` carries
  `ALIVE2_FLAGS="--smt-to=300000"`, which the shared runner appends to the
  `alive-tv` invocation (and records in `alive2/result.txt` as part of the
  command line).  With the default budget every function ends in
  `ERROR: Timeout` / `failed-to-prove`, which is *not* green.
- SAW uses `abc` for this cell (`llvm_verify ... abc`).  z3 ran for more than
  15 minutes on the first obligation without closing it; abc proves the same
  goals in roughly 3-6 minutes each.  abc is a genuine bit-blasting prover
  and SAW reports `Provers used: abc_verilog` in `saw/result.txt`.  The shared
  runner puts the SAW bin directory (which contains `abc`) on `PATH`.
- The machine is shared with other wave tasks; timings vary.

## Bounds and why they are disclosed

`EV_SCRIPT_MAX = 8`.  This is the only place the cell is partial: Core's
`IsPushOnly` is a loop over an arbitrary-length script, and the leaf has no
heap vectors, so an 8-byte packed input is the largest faithful bound that
keeps the leaf loop-free.  The general walk is the E5 `GetScriptOp` residual.
For the claimed domain the decoder is exact (all length-field widths and all
truncation paths are modelled).

## Mutation proposals (not executed)

1. `opcode <= 0x60` -> `opcode <= 0x61` in either leg.  Expected Alive2
   counterexample at one-byte script `0x61`; SAW failure on all three
   functions.
2. Ignore PUSHDATA1 truncation.  Expected counterexample at `len = 2,
   script = 0x4c01`.
3. In `cell_pushonly_early`, consult the predicate even when the policy flag
   is off (reuse the C result in the flag-off arm); expected equivalence
   *still* green but a mutation that *drops* the flag test entirely would
   differ at `sigpushonly = 0` only in the "check not applicable" value if the
   mutant returned an error — the useful mutant is dropping the `SIGPUSHONLY`
   error ordinal, which SAW catches.

The unmutated cell is green first.
