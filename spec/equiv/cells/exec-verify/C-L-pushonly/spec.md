# exec-verify/C-L-pushonly

`CScript::IsPushOnly` on bounded scripts, and the two `SIG_PUSHONLY` checks
that use it (`SIGPUSHONLY` pre-check and the P2SH arm).

## The region

```c
// script.cpp:266-285
bool CScript::IsPushOnly(const_iterator pc) const {
    while (pc < end()) {
        opcodetype opcode;
        if (!GetOp(pc, opcode)) return false;   // GetScriptOp failure
        if (opcode > OP_16) return false;       // OP_16 = 0x60
    }
    return true;
}

// interpreter.cpp:2022-2024 (SCR-010)
if ((flags & SCRIPT_VERIFY_SIGPUSHONLY) != 0 && !scriptSig.IsPushOnly())
    return set_error(serror, SCRIPT_ERR_SIG_PUSHONLY);

// interpreter.cpp:2065-2066 (SCR-006)
if (!scriptSig.IsPushOnly())
    return set_error(serror, SCRIPT_ERR_SIG_PUSHONLY);
```

`GetScriptOp` (script.cpp:313-363) decodes one instruction: a direct push for
0x01-0x4b (the opcode is the payload length), PUSHDATA1/2/4 with 1/2/4
little-endian length bytes, no payload for opcodes >= 0x4f, and a decode
failure whenever a length field or payload runs past the end of the script.

## What is proved

- the predicate itself, symbolically, for every 0..8-byte script;
- the exact `SIG_PUSHONLY` (26) result and its precedence: with the policy
  flag off, the check is not consulted at all; in the P2SH arm the check is
  unconditional once the arm is entered;
- all three functions against a third encoding (a Cryptol fold over the
  GetScriptOp table), and the two legs against each other (Alive2).

## What is not proved

- scripts longer than 8 bytes (E5 `GetScriptOp` residual);
- the *ordering* "before eval" in SCR-010 — whole-VerifyScript composition
  (SCR-001 residual);
- the P2SH arm after the check (handoff: `C-L-p2sh-handoff`; witness arms:
  `C-L-verifyscript-tail`).

## Bounds

| input | bound | why |
|---|---|---|
| script length | 0..8 bytes | packed u64; longer = marker 3 |
| length field | full 1/2/4 bytes | PUSHDATA4 is decoded, just cannot fit a payload in 8 bytes |
| opcode byte | full 0..255 | exact |

The eight-step unrolling is exact for the bound: every executed step consumes
at least one byte, so an 8-byte script cannot need a ninth step.
