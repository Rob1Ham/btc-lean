# exec-verify/C-L-flags-domain — notes

## Design

The cell is deliberately *only* the flag-domain guard.  The `VerifyScript`
asserts are preconditions, not checks; the contract (tape.md §5) totalizes them
into result 2.  Modelling them as a pure predicate is therefore exact — there
is no engine code between the mask and the assert.

Two independent encodings make the Alive2 result non-trivial:

- C leg: the guard of `shims/core/entry.cpp:93-102`, branch-per-condition,
  followed by the assert predicates of `interpreter.cpp:2113-2114,2124`.
- L leg: a branchless bit-level formulation written from the contract table
  (`tape.md` §5) in the typed-flag shape of
  `Defs.lean:verifyScriptFull` (`ScriptFlags`/`PolicyFlags` carry `witness`
  and `cleanstack` as independent booleans).

SAW verifies both against `saw/cell.cry`, which is a third encoding: a
condition table read off the contract text.

## Build and tools

```text
clang++-20 (Ubuntu clang version 20.1.2)
llvm-extract/llvm-dis 20.1.2
alive-tv 20.0 (LLVM 20.1.2 build)
SAW 1.6 (68eed5f, release-1.6), bundled z3
```

`build/` is generated by `findings/wave16/01-exec-verify/tools/lib.sh`
(`ev_build_pair`): `-O1 -fno-strict-aliasing -fno-discard-value-names`,
`-c -emit-llvm`, then `llvm-extract --func=<fn> --recursive` per function so
each Alive2 comparison sees exactly one exported function per module.

`build/` is git-ignored (`spec/equiv/.gitignore`); the certificates include
the generated `.ll`/`.bc` hashes, so `sha256sum -c` is meaningful after a cell
run, which is also how `make equiv` exercises the cells.

## Limits

- No abort path, no debug-build semantics.
- No caller-side flag derivation (`validation.cpp:2249-2288`,
  `kernel/chainparams.cpp:115-118`); that is out of the tape.  SCR-015/016 are
  filed as no-go for this reason (see the task report).
- The predicate says nothing about *whether* a given mask is sensible policy;
  only that it cannot trip the two asserts once the ABI accepts it.

## Mutation proposal (not executed)

Drop the `CLEANSTACK ⇒ (P2SH ∧ WITNESS)` conjunct in the L leg.  Expected:
Alive2 counterexample at `flags = 0x100` (C returns 0, L returns 1), SAW
failure of `cell_flags_guard` and `cell_flags_implication` at the same mask.
The unmutated cell is green first, as required for a usable mutation.
