# exec-verify/C-L-flags-domain

Bounded, symbolic proof of the flag-combination constraints the Core
`VerifyScript` asserts state, at the level the ABI contract fixes.

## What this is

Core's `VerifyScript` has two hard preconditions on its `flags` argument,
expressed as `assert`s:

```c
// interpreter.cpp:2110-2117 (CLEANSTACK arm)
if ((flags & SCRIPT_VERIFY_CLEANSTACK) != 0) {
    assert((flags & SCRIPT_VERIFY_P2SH) != 0);      // 2113  SCR-009
    assert((flags & SCRIPT_VERIFY_WITNESS) != 0);   // 2114  SCR-009
    if (stack.size() != 1) return set_error(serror, SCRIPT_ERR_CLEANSTACK);
}
// interpreter.cpp:2120-2126 (WITNESS tail)
if (flags & SCRIPT_VERIFY_WITNESS) {
    assert((flags & SCRIPT_VERIFY_P2SH) != 0);      // 2124  SCR-014
    if (!hadWitness && !witness->IsNull())
        return set_error(serror, SCRIPT_ERR_WITNESS_UNEXPECTED);
}
```

An `assert` is not a verdict and cannot be an equivalence observable.  The
contract fixes a total replacement (`contract/tape.md` §5):

> Core's `VerifyScript` also asserts two implications; to keep the ABI total
> instead of aborting a debug build, violations are **2**:
> `WITNESS ⇒ P2SH`, `CLEANSTACK ⇒ P2SH` and `WITNESS`.

`shims/core/entry.cpp:93-102` implements that guard.  This cell proves that the
guard and the asserts describe the same set of masks, and that no accepted mask
can reach either assert.

## The three proved functions

All inputs are a single symbolic 64-bit `flags` word; nothing is a closed
witness.

| function | meaning | proved value |
|---|---|---|
| `cell_flags_guard` | ABI accepts the mask | 1 iff bits 21..63 clear ∧ WITNESS⇒P2SH ∧ CLEANSTACK⇒(P2SH∧WITNESS) |
| `cell_flags_assertsafe` | both Core assert predicates hold (high bits ignored) | the same two implications |
| `cell_flags_implication` | guard-accepted ⇒ assert-safe | **constant 1 for all 2^64 masks** |

`cell_flags_implication` is the row statement: after the ABI guard, the
asserts at 2113-2114 and 2124 are unreachable, so the contract's result `2`
carries exactly the assert's content.

## What is not proved

- The abort path of an assert in a debug build (no verdict, out of contract).
- Anything below the guard: witness dispatch, P2SH, CLEANSTACK's stack test,
  EvalScript.  `cells/exec-verify/C-L-verifyscript-tail` covers the tail
  checks with `flags` already in domain.
- That Core's *callers* only build masks from the flag tables
  (`setBlockScriptFlags`, policy).  That derivation is outside the ABI: the
  tape carries `flags` directly (see the SCR-015/016 no-go in
  `findings/wave16/01-exec-verify/report.md`).
