# exec-verify/C-L-w65-scr008-cleanstack-arms — notes

## Why this cell exists

SCR-008 is "exactly 1 element after all evaluation (flag; pol.; implicit in
witness)". Two earlier cells speak to it:

- `exec-verify/C-L-verifyscript-tail` proves the tail including CLEANSTACK, but
  its L leg *deviates* from Lean on the P2SH-wrapped witness arm: it uses the
  constant 1 (Core's `resize(1)`) instead of the model's recomputed length.
  That deviation is disclosed in that cell's notes, and it is why the cell
  cannot vouch for the pinned model on this row.
- `exec-verify/C-L-w32-cleanstack` proves only the terminal `!= 1` test over a
  symbolic length, and records the divergence separately.

This cell replaces both, for SCR-008 purposes, with a **faithful** L leg: the
`finalLen` expression is transcribed exactly as the pinned model writes it,
including the `isWitnessProgram spk` test. The result is green only on a
declared input domain; the excluded set is the model divergence, and it is
reproduced red in `findings/wave65/02-scr008-full-cell/`.

## Design

Both legs take the same eleven symbolic inputs. C is a line-cited excerpt in
Core's order. L is a reviewed transliteration of `p2shInner` +
`verifyScriptFull`, written in Lean's shape: `hadWitness` is recomputed from
the two arm predicates, the 42 guard precedes the cleanstack check because
`p2shInner` is matched before the ok-path tail, and `finalLen` uses
`bare_wit` (the scriptPubKey predicate) rather than the redeem script.

SAW checks both legs against `saw/cell.cry`, a condition table read off the
row table in `spec.md`. The Cryptol table is not a transliteration of C or L:
it is the shortest statement of the precedence order (41 -> 42 -> 30 -> 43 ->
pass) plus the final-length selection.

## The declared domain, and why it is exactly this

`ev_scr008_in_domain()` (src/common.h) is called by both legs before anything
else, and returns the sentinel `0xffffffffffffffff` on the complement. Two
clauses:

1. `not (spk_wit && spk_p2sh)` — a scriptPubKey cannot be both a witness
   program (leading `OP_0`/`OP_1..OP_16`) and P2SH (leading `OP_HASH160`,
   23 bytes). Without this clause the unconstrained symbolic inputs would
   invent the intersection and Alive2 would report a counterexample that no
   real script reaches. (The wave-32 probe made exactly this mistake, with
   `bypass_kind = 4` outside its documented `{0,1,2}`.)
2. `not (p2sh && spk_p2sh && witness && redeem_wit && cleanstack &&
   ss_push_ok)` — F-DIV-W32-01. Core resizes to 1 at 2102; the pinned Lean
   `finalLen` keeps the redeem-script length, so a valid P2SH-P2WPKH/P2WSH
   spend is rejected with CLEANSTACK. `ss_push_ok` is part of the clause
   because with a non-push scriptSig both models return 42 first; the set
   excluded is exactly the set where the verdicts differ.

Everything else is inside the domain, including the wrapped-witness arm with
`cleanstack = false` and the wrapped-witness arm with `cleanstack = true` and
`ss_push_ok = false` (42 wins in both models).

## Bounds

| input | bound | why |
|---|---|---|
| `st_n` (post-spk depth) | 0..3 | feeds only `== 1`; the region has no loop |
| `inner_len` (subscript depth) | 0..3 | same |
| `sig_n` | 0..3 | only `== 0` is read |
| `wit_n` | 0..3 | only `!= 0` (`IsNull`) is read |

These are input domains, not weakened predicates.
