# exec-verify/C-L-p2sh-handoff

The P2SH stack handoff: `stackCopy` captured after `scriptSig` evaluation is
restored for the subscript evaluation, and the last scriptSig stack element
becomes the subscript script.

## The region

```c
// interpreter.cpp:2028-2033
std::vector<std::vector<unsigned char> > stack, stackCopy;
if (!EvalScript(stack, scriptSig, ...)) return false;
if (flags & SCRIPT_VERIFY_P2SH)
    stackCopy = stack;                    // capture, SCR-007

// 2062-2078
if ((flags & SCRIPT_VERIFY_P2SH) && scriptPubKey.IsPayToScriptHash()) {
    if (!scriptSig.IsPushOnly()) return set_error(serror, SCRIPT_ERR_SIG_PUSHONLY);
    swap(stack, stackCopy);               // restore, SCR-007
    assert(!stack.empty());               // unreachable
    const valtype& pubKeySerialized = stack.back();
    CScript pubKey2(pubKeySerialized.begin(), pubKeySerialized.end());
    popstack(stack);                      // the subscript's starting stack
    if (!EvalScript(stack, pubKey2, ...)) return false;   // SCR-005 re-eval
```

and the shape predicate itself (`script.cpp:224-232`):

```c
return (this->size() == 23 &&
        (*this)[0] == OP_HASH160 &&   // 0xa9
        (*this)[1] == 0x14 &&
        (*this)[22] == OP_EQUAL);     // 0x87
```

## What is proved

1. **Shape (exact).** `IsPayToScriptHash` reads exactly four fields — size,
   byte 0, byte 1, byte 22.  The cell takes those fields symbolically and
   proves the predicate for every length and every byte value; the other 19
   bytes cannot influence the result.  There is no bound to disclose.
2. **Restore (SCR-007).** For every captured post-scriptSig stack of depth
   0..3, the stack handed to the subscript is the captured stack minus its
   top, with order and contents preserved, and the popped top is the
   redeemScript.  The swap's second half (the old scriptPubKey stack parked
   in `stackCopy`) is dead state in Core and is not modelled; Lean does not
   model it at all.
3. **Gating.** The handoff composition (`p2sh ∧ spk_shape`) decides entry;
   all other combinations are marker 3.

## What is not proved

- The scriptSig and scriptPubKey `EvalScript` calls (E5 residual), the
  push-only check (SCR-006, `C-L-pushonly`), and the subscript
  `EvalScript(pubKey2)` and its EVAL_FALSE checks (SCR-005's "re-eval"
  half — E5 residual).
- `assert(!stack.empty())` (2074): unreachable given the P2SH shape, but the
  reasoning lives in the scriptPubKey evaluation, not this cell.  Excluded.
- The P2SH-witness arm (2088-2105): covered by
  `C-L-verifyscript-tail` and `C-L-failure-propagation`.
