# exec-verify/C-L-eval-empty

The zero-op `EvalScript` frame: `stack` handoff, the loop-entry condition, and
the trailing conditional check.

## What this is

`EvalScript` is a `for` loop over opcodes with a local `vfExec` conditional
vector:

```c
// interpreter.cpp:449
for (; pc < pend; ++opcode_pos) { ... }
...
// interpreter.cpp:1248-1250
if (!vfExec.empty())
    return set_error(serror, SCRIPT_ERR_UNBALANCED_CONDITIONAL);
return set_success(serror);
```

If the script parses to no opcodes the loop body never runs: no push is read,
no stack element is touched, no opcode is counted, and the only observable
decision is the trailing conditional check.  This is SCR-003.

## Model

`cell_eval_frame(ops_len, vf_depth, st_n, b0..b3)`:

| ops_len | vf_depth | observable |
|---|---|---|
| 0 | 0 | (verdict 1, err 0, stack unchanged) |
| 0 | != 0 | (verdict 0, err 20 UNBALANCED_CONDITIONAL, stack unchanged) |
| != 0 | any | (verdict 3 = out-of-model marker) |

The stack is part of the observable (depth + four one-byte items), so
"unchanged" is checked symbolically rather than asserted in prose.

## What is not proved

- Any opcode step: `GetScriptOp`, the dispatch switch, CScriptNum, the
  201-opcode and 520-byte limits, `stepChecked`'s STACK_SIZE guard.  That is
  the E5 residual; a non-empty script is out of this cell (marker 3).
- `SCRIPT_SIZE` (SCR-018) — not modelled.
- The Lean fuel counter: the cell uses the `_+1, [], st` case only.
