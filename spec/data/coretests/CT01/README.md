# CT01 — Bitcoin Core merkle-block / PMT test mining

Case set: CT01, 2026-10-16.
This directory contains the CT01 case set.

Purpose: mine Core's merkle-block / partial-merkle-tree (PMT) tests at the
pinned tree — `src/test/merkleblock_tests.cpp` + `src/test/pmt_tests.cpp`
(the expected `pmt_tests.h` does not exist at the pin; see PROVENANCE) —
extract every extractable test vector, run the merkle-path / inclusion
semantics through the merkle implementation
(`spec/core/Bitcoin/Capstone/Merkle.lean` = `merkleRootOf`/`pairHash`/
`merkleRootOfBlock`, BLK-005..BLK-013) via a line-anchored python mirror
(`spec/db/findings-af/CT01-pmt-mirror.py`) plus a Lean executable mirror
(`run/`, module `CT01Run`), and land the decisive cases here.
Findings + pass/fail table: `spec/db/findings-af/CT01.md`.
Divergences are numbered `F-CT01-xxx`.

## Case boundaries (read before touching anything here)

* **CT01**: `CPartialMerkleTree` / `CMerkleBlock` /
  `merkleblock.{h,cpp}` semantics (build/extract/malleability), the
  merkleblock_tests + pmt_tests test surfaces,
  `MerkleComputation`/`TransactionMerklePath`
  (consensus/merkle.cpp:98-190) + the fuzz/merkle.cpp path-replay
  (inclusion verification) as mining targets.
* **Merkle-block module (BLK-005..BLK-013)**: `consensus/merkle.cpp`
  `ComputeMerkleRoot` block-lane, `merkle_tests.cpp` (7 cases:
  merkle_test, _empty_block, _oneTx_block, _OddTxWithRepeatedLastTx_block,
  _mutated_return_value, _LeftSubtreeRightSubtree, _BlockWitness),
  merkle mutation (BLK-011/BLK-012, `merkleMutationFree`,
  `spec/core/Bitcoin/Block/Connect.lean:195-241`).
* **CVE-2012-2459 block-level**: `spec/vectors/cve/cve-2012-2459*/`.
  CT01 covers the *PMT-side* counterpart (pmt_malleability /
  merkleblock.cpp:124-128) only; cross-referenced, not duplicated.
* Out of scope: `db/rules.yaml` and other case directories. CT01 writes
  only `coretests/CT01` and `findings-af/CT01*` in the source tree.
