# axiom-manifest-wallet.txt - static axiom contract for wallet declarations
#
# This is the wallet-only manifest. It never lists a consensus declaration
# and it is not merged with spec/db/axiom-manifest.txt.
#
# Scope: every public theorem/lemma declaration in the two additive wallet
# source trees:
#   spec/core/Bitcoin/Wallet/**/*.lean          (Bitcoin.Wallet.*)
#   spec/proofs/BitcoinProofs/Wallet/**/*.lean  (BitcoinProofs.Wallet.*)
# Four root-level helper lemmas declared before a namespace in a wallet file
# are listed under their actual root names. The probe is
# spec/scripts/wallet_axiom_probe.lean, generated from those sources by
# spec/scripts/wallet_axiom_probe.py and run from spec/proofs.
# Private theorems cannot be named from another module; local scratch files
# named Probe*.lean are not part of the proof surface. Both exclusions and
# the exact file snapshot are documented in
# wallet-review/peer-reports/WALLET-AXIOM.md.
#
# Permitted axiom set for every wallet theorem: the ordinary Lean trio.
# A declaration may use a subset of it, but no sorryAx, no native/compiler
# trust axiom, and no wallet-specific axiom is permitted.
#
# Format:
#   expected: [propext, Classical.choice, Quot.sound]
#   decl: <fully-qualified-name> -> [<axioms actually expected>]
#
# Generated from 838 public wallet theorem/lemma declarations
# (120 core, 714 proofs). Observed footprints:
#   300 declarations use [propext, Classical.choice, Quot.sound]
#   362 use [propext, Quot.sound]
#   117 use [propext]
#   59 use no axioms
